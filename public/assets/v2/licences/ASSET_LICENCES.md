# V2 asset licence ledger

Per-asset attribution record for every externally sourced file under
`public/assets/v2/`. Self-authored, in-house assets (procedural code,
Blender files modelled from scratch for this project) do not need an
entry here — only assets whose rights originate outside this project.

**Rule (Implementation Rule #9 / #10 / #11): never fabricate an entry.**
If an asset's licence cannot be confirmed, it must not be marked
`status: "production"` in the manifest, regardless of visual quality.

Permitted: commissioned original art, self-modelled Blender assets,
licensed asset packs with a redistributable licence, CC0/permissive
assets, approved generated textures, and using commercial games
(RuneScape, Hogwarts Legacy, Guild Wars 2, etc.) strictly as **visual
quality references**, never as a source of copied/extracted assets.

Not permitted: auto-pulling assets from the internet without a checked
licence, including copyrighted assets from any existing commercial game,
or recreating an asset that is recognisably derived from one.
